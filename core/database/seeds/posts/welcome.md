# 欢迎使用我的博客

欢迎使用 **LiteNote**！这是你的第一篇文章，用来帮助你快速熟悉站点。

## 你可以从这里开始

- **写文章**：进入 [后台](/admin) → 文章 → 写文章，支持 Markdown 与封面图。
- **发滔客**：短动态、图片和心情标签，适合随手记录。
- **分享音乐**：上传或关联曲目，前台可播放与评论。
- **查看动态**：文章、滔客、音乐与插件活动会汇总到 [动态页](/activity)。

## 站点设置

在后台 **系统设置 → 基础设置** 中可修改：

- 站点标题、副标题、描述与关键词
- 固定链接规则、评论与邮件通知

修改后刷新前台即可看到变化。

这是示例内容，你可以直接在后台编辑或删除这篇文章。祝写作愉快！
